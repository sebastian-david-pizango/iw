Este es nuestro primer intento de página web

Este portal ha sido diseñado siguiendo las recomendaciones oficiales del tutorial de CSS de la W3C, pero con un enfoque moderno, limpio y accesible.

La navegación se realiza mediante el menú de arriba. Hemos mejorado el diseño con un estilo moderno y profesional.

Disfruta de una interfaz con vidrio esmerilado, gradientes suaves y una tipografía contemporánea que hace que la lectura sea un placer.
